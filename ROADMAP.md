# Roadmap

## v1.0.0 — Complete portfolio release

The repository is feature complete for its portfolio objective.

## Potential production extensions

- Add a self-hosted private agent pool with network access to private AKS and private endpoints.
- Add signed-image admission through Ratify, Kyverno, or Gatekeeper integration.
- Add Azure Monitor or Datadog deployment annotations and release verification.
- Add multi-repository template consumption through a dedicated pipeline-template repository.
- Add ephemeral integration clusters for live Helm and rollback tests.
- Add Azure DevOps Checks API automation after organization governance is finalized.
- Add service-specific templates for .NET, Java, Node.js, and data pipelines.
